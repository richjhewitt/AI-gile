# New icon pack

Everything to get a new AI-gile icon designed, close to the current one.

- `current-icon.png`, `current-icon-waiting.png`, `current-icon.ico`: the icon in use now (desktop app, 256x256)
- [chatgpt.md](chatgpt.md): the design brief and the prompt to paste into ChatGPT
- [designer-message.md](designer-message.md): a friendly message for a designer friend, ready to send

When a design is picked: drop its `icon.png` (256x256), `icon-waiting.png` and an SVG if there is one into this
folder and tell the lead on the board; the team swaps it into the app, the favicon and the website.
