# AI-gile icon: brief for ChatGPT

**How to use:** open ChatGPT, attach `current-icon.png` and `current-icon-waiting.png`, then paste everything in the box below.

---

```
You are a senior brand and icon design consultant. I'd like a refreshed app icon for my product, AI-gile.
I'm attaching the current icon (and its "something's waiting" variant). I like the current one, so treat
this as an evolution, not a reinvention: same spirit, more polish and character.

ABOUT THE PRODUCT
- AI-gile is a kanban board where AI dev teams do the work and a human owner steers: the owner raises ideas,
  says GO, and tests what the teams hand back. Think Trello/Jira, but the team members are AI agents.
- It runs locally on Windows: a desktop app (taskbar icon), a browser tab (favicon) and a small website.
- Tone: friendly, calm, a bit playful, never corporate. It also has a night mode (dark, warm, sleepy).

THE CURRENT ICON
- Rounded square, solid blue #3B6CF6, with three white bars of different heights (kanban columns / a rising
  board).
- "Waiting" variant: a purple diamond #A855F7 on the top-right corner, shown when something waits on the owner.

WHAT I'D LIKE
1. Three directions, from "almost the same, just refined" to "a bolder step", all clearly recognisable as
   the same family as the current icon.
2. Keep: rounded square, blue as the main colour, the three-column board idea.
3. Consider: a subtle hint of AI or a team (without robots, brains or sparkles clichés), better proportions
   and optical balance, a slightly richer blue (a gentle gradient is OK if it still reads flat at 16px).
4. It must read at 16x16 and 32x32 (taskbar, favicon) as well as 256x256 and 512x512.
5. The "waiting" badge must still fit on the top-right corner without hiding the mark.
6. No text or letters in the icon.

PLEASE DELIVER
- For each direction: the icon at 512x512 on a transparent background, a one-paragraph rationale, and a
  16px / 32px preview so I can see it small.
- Then your recommendation and why.
- For the one I pick later: the "waiting" variant with the purple diamond, a dark-mode check, and hex codes.
```

---

**Follow-ups that help:**
- "Show direction 2 at 16px, 32px and 256px side by side on a dark and a light taskbar."
- "Make it a flat SVG-style version with no gradient."
- "Now the waiting variant with the purple #A855F7 diamond, same as the current one."

**What the board needs back in the end:** a 256x256 PNG (`icon.png`), the waiting version (`icon-waiting.png`)
and, if possible, an SVG. The team turns those into the `.ico`, favicon and website logo.
