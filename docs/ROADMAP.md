# Roadmap

One page: what ships when. Dates follow the work, not the calendar.

## Now: pre-alpha (prototyping)
- Desktop app built on Electron: Windows first, Linux AppImage (AIG-409)
- The board in any browser, phone pages, install to home screen (AIG-410)
- Friends try it in playgrounds on Rich's own server

## v0.1: first tag
- Merge to main, tag v0.1, private backup on GitHub (AIG-247)

## v0.42: closed alpha
- Invite-only, named for Douglas Adams (AIG-668)
- test.aigile.lol, then aigile.lol with the relay and invite links (AIG-653, AIG-655)
- Register interest on aigile.lol (AIG-754)
- **Native Android app** (AIG-741 to AIG-750): pair, board, cards, For you, messages, calm alerts, offline
- Mail: read, reply, cards from mail (AIG-902 to AIG-910)

## Beta
- **Native Windows and Linux apps** replace the Electron prototype
- Public site with live board view and the licence form (AIG-698, AIG-619)
- Every language translated and native-checked (AIG-503 to AIG-514)

## After beta: Apple and the rest
- macOS: signed so it opens without warnings (needs an Apple Developer account)
- iOS, then HaikuOS (AIG-806; Sikosis offered to test)
