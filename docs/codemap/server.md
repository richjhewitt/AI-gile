# Code map: server, API routes, local settings

## Server files

| `server.js` | Wiring and http plumbing: dev build id, route dispatch (`/api/*`), static files from `public/`, JSON errors |
| `lib/store.js` | Config paths and port; `load`/`save` of `data/<slug>.json`; `localSettings`; `summary` (project card on the home page); `attention` (needs a poke: asleep with work, or stuck); card rules (`cleanCard`, `toTeam`, `findCard`, `docList`, `bad`/`need`); `projectOrder` / `setProjectOrder` / `byOrder`: your project order from the left rail (AIG-189), in data/project-order.conf |
| `lib/routes.js` | Combines `lib/routes/*.js` (`meta`, `projects-cards`, `comments`, `team-dms`, `docs-inbox`; `ctx.js` holds their shared requires and helpers) in match order. Each is `[method, regex, handler]`; see the markers: projects, cards, comments/verdicts/tasks/pokes, team/log/updates feed, docs (incl. `/file`) and inbox |
| `lib/onboard.js` | `connectFolder`: marked notes block, merged comment hooks and default team permissions, git init for a new folder, git exclude; `getPermissions`/`setPermissions` and the `PRESETS` ticks for the 🔐 Permissions dialog |
| `lib/presence.js` | Team presence (`heard`, `presenceOf`, `heardFromFolder`) and the background runner: `startTeam`/`nudge` (agent command run hidden in the project folder, log in `data/logs/<slug>.log`, one run per team), `restartTeam`, `logTail`; where a team runs (AIG-153): `runIn` (p.runIn / p.runCmd, else `runs` in aigile.local.json), `openWindow` for a terminal window, VS Code or the owner's command (only background runs are tracked; `opened` remembers when a window was opened; `AIGILE_NO_WINDOWS` only logs it); verbose (AIG-154, `p.verbose`, switch in 🎨 Look): background runs get `--output-format stream-json --verbose` and `readable()` turns each event into a short log line (🔧 Bash: …, ✏️ Edit …, 💬 text); the page's 👁 Watch (`watchTeam`/`renderWatch` in board.js, pop-out `#/pop-watch/<slug>`, texts `eye.*`) polls `/agentlog`, and `logTail` reads only the last 256 KB |
| `lib/quiet.js` | Going quiet: `setQuiet` (📣 card to every team with open work, starts sleeping ones, night mode file `data/quiet.state`), `quietSince` |
| `lib/standup.js` | Stand-ups (AIG-133..135): `callStandup` (📣 card with `standup: { at, reports }` in each chosen team's For the team, wakes sleeping teams, skips a project that already has an open one), `reportStandup` (one member's done / next / blockers, replaces their earlier answer, says who is left), `standupReport` (newest stand-up per project, people, and the real blockers) |
| `lib/attachments.js` | Files attached to replies (AIG-77): `saveAttachment` (base64 upload, 10 MB), `attachmentsFor` (checks a comment's ids), `fileOf`; stored in `data/attachments/<slug>/` |
| `lib/logos.js` | Project pictures and the app logo (AIG-175): `saveLogo` (base64 upload or a typed local path; png/jpg/svg/ico/webp, 1 MB; refuses `% " $ `` in paths), `removeLogo`, `logoFile`, `urlFor`; stored as `data/logos/<slug>.<ext>` and `data/logos/_app.<ext>`. `p.logo` is the URL (`/api/projects/<slug>/logo?v=..`), `S.look(p).logo` carries it everywhere; the page shows it with `pic(logo, emoji)` (core.js). App logo: `/api/app-logo`, `meta.appLogo`, `applyAppLogo` (app.js) swaps the favicon and header, `desktop/main.js` `appIcon()` uses it for the window |
| `lib/avatars.js` | Profile pictures (AIG-150): the owner's is `_me` in logos.js (`/api/me-picture`, `meta.ownerPic`, Setup). The agents' picture library is the folder `avatarsDir` (aigile.local.json, default `data/avatars`): `library`, `libraryStatus` (who wears what, `GET /api/avatars`), `avatarFile` (`GET /api/avatars/<file>`), `pickAvatar` (the team route gives a new member a free one; `aigile avatar` picks). Stored as `m.avatar` on the roster entry. Page: `face(name, team)` (core.js) next to comment authors, DM messages and the team table; DMs show `leadPic` |
| `lib/dm.js` | Private DMs (AIG-110, design in `docs/DMS-DESIGN.md`): `identity` (X25519 + Ed25519 keys and a random mailbox id in `data/keys/identity.json`), settings (`on`, `relay`), contacts, invites (`createInvite`/`acceptInvite`, the sealed hello), `safetyCode` (6 words), `seal`/`receive` (ephemeral X25519 + HKDF-SHA256 + AES-256-GCM, Ed25519 signature; failures kept as not verified), attachments sealed inside a message (AIG-111: `saveFiles`/`fileOf`, kept in `data/dms/files/<contact>/`, 8 MB per message), the outbox (`flush`), `poll` (signed collect + ack, every `AIGILE_DM_POLL_MS`, default 4s, only while on) |
| `lib/share.js` | Sharing a project with a friend (AIG-304, design in `docs/SHARING-DESIGN.md`): the share wire format (`{ t: 'share', link, seq, kind }` DM payloads, sealed by dm.js; dm.js hands them over through `dm.hooks.share` and calls `dm.hooks.ended` on block/remove), `offer` / `accept` / `decline` (both sides need a checked safety code; one link per project; offers last 2 days), the per-project 🔗 switch (`patch {on}`: off drops and counts, `droppedOff`), `ping` (👋 check the link: an `ack`, answered with an `ack`, sets `lastHeard`), `unlink {forget?}` (forget removes cards and comments tagged `from: 'share:<link>'`). `receive` order: shape and `CAPS`, envelope age (8 days), the link's own contact, `seq` (at or below the last seen: `stale`), link-end, switch, daily caps, kind. | `relay/relay.js` | The DM relay (AIG-112): standalone, zero deps, run on a server. Mailboxes of sealed envelopes in `RELAY_DATA/<box>/`; POST drops one, a signed GET collects, a signed POST `/ack` deletes; first signed collect claims a mailbox; replay guard (timestamp + nonce), 12 MB limit, per-IP rate limit, 7-day expiry |
| `lib/limits.js` | `recordLimits` / `limitsHistory` for the plan usage log |
| `lib/usagecheck.js` | Check usage now (AIG-151): `checkUsage` starts Claude hidden (one tiny Haiku message, user settings only, one harmless tool), waits for the status line to post a reading, closes it; auto mode (`startAuto`, settings in data/usage-check.conf) checks when the last reading is over an hour old |
| `lib/trial.js` | 🧪 Try it as a new user (AIG-201..203): `startTrial` runs a fresh, empty board on port 4400 with made-up project folders (AIGILE_HOME) and a do-nothing agent; `stopTrial` |
| `tools/trial/pretend-team.js` | The trial's pretend team (AIG-205): run by the trial board instead of an AI. Seeds a new project (lead + cards in each column), answers ideas with two cards and a GO? plan, hands work over after Go, answers comments, stand-ups and going quiet |
| `lib/watchman.js` | 🌙 Night watchman (AIG-199): while going quiet, every 10 min plus a quick look every minute (AIG-277): restarts teams cut off mid-card, flags a card stuck after 3 tries (it stops only itself), wakes idle teams with work, nudges sessions idle in their wait, waits out the usage limit (`limitHit`, `limitFromReadings`, AIG-283/265), starts the AI tester once a night (AIG-292); `stopWatch` returns a summary per project and keeps the night chat in data/watchman.last. | `lib/tester.js` | 🤖 AI tester runs (AIG-291): `startTester` (one hidden Sonnet run over unchecked tests, brief docs/TESTER.md, log data/logs/_tester.log), `testerStatus`, `testsWaiting`; routes GET/POST /api/tester |
| `lib/usage.js` | Token usage per project, read from the agents' local session logs; `runTokens` sums one background run (AIG-266): a `=== tokens` line after `=== exited` in the team log, a row in `data/logs/_runs.jsonl`, a table on the Usage page via `GET /api/usage/runs`; the row also has cards worked on (`cardsWorked` in presence.js), models, fresh/cache-write/read/out tokens, Read count + result chars, Grep count (AIG-299); QA area `runtokens` (team-quiet) |

## API routes
All in `lib/routes/*.js` (patterns are the regexes there). The list with payloads is in the README's API table. Unknown `/api/*` paths return 404 JSON from `server.js`. A handler may return a promise (the DM routes talk to the relay).
- DMs: `GET /api/dms` (on, relay, mailbox, contacts, lastPoll), `POST /api/dms/settings` `{on?, relay?}`, `POST /api/dms/poll`, `POST /api/dms/invites` `{name?}`, `POST /api/dms/accept` `{code, name}`, `GET /api/dms/contacts`, `PATCH`/`DELETE /api/dms/contacts/:id` (`{name?, checked?, blocked?}`), `GET`/`POST /api/dms/contacts/:id/messages` (`{text, attachments?: [{name, type, data}]}`), `GET /api/dms/contacts/:id/files/:fid`, `GET /api/dms/contacts/:id/messages/:mid/raw` (what the relay sees).
- Sharing (AIG-304): `GET /api/shares[?slug=]`, `POST /api/shares` `{slug, contact, allow?}` (offer), `PATCH /api/shares/:id` `{on}` (the 🔗 switch), `POST /api/shares/:id/accept` `{slug, allow?}`, `/decline`, `/ping`, `/unlink` `{forget?}`.

## Local-only settings
`aigile.local.json` (git-ignored; values are machine-specific):
- `usageDir`: folder of the agents' session logs (`AIGILE_USAGE_DIR` overrides).
- `globalSettingsFile`: the agent's global settings file, used to show how to switch the status line on.
- `agent.command`: program background runs start (one `*` path segment allowed; `AIGILE_AGENT_COMMAND` overrides).
- `agent.notesFile`, `agent.settingsFile`: file names `onboard` writes in a project folder.
- `avatarsDir`: the agents' picture library folder (AIG-150; empty: `data/avatars`).
- `dmRelay`: default DM relay address (`AIGILE_RELAY` overrides; `POST /api/dms/settings` can set one too).
- `WAYS-OF-WORKING.md` (repo root) is the owner's private rules for every team, git-ignored; a new install gets `docs/starter/WAYS-OF-WORKING.md` with the name filled in (`ensureWays` in lib/setup.js).
- `owner`: the board's human, whose comments wake teams and who gets questions and tests (default Rich; `AIGILE_OWNER` overrides). Code calls this person `isRich()` / `me()`.
- `lead`, `night` (AIG-235): what kind of lead, set by the Setup questionnaire or its switches (`prefs` in `GET`/`POST /api/setup`, `prefsOf`/`setPrefs` in lib/setup.js): `lead.tidyCards` (AIG-234), `lead.chatty` (default for new projects; `chattyAll` also sets every active project), `lead.go` (`ask`/`small`: one rule line in `aigile brief`), `night.watchAll` (false: going quiet ticks no project for the watchman; an empty `watch` list means none). Dev words explained stays per browser (`aigile.explain`).
- `runs` (AIG-153): `where` (background, terminal, vscode, other) and `cmd` (the Other command, `{folder}` filled in): where every team runs unless its project picks its own in 🎨 Look (`p.runIn`, `p.runCmd`). Saved through `prefs.runIn` / `prefs.runCmd` in `POST /api/setup`.
