# Code map: page (public/)

`index.html` is the shell only. The scripts are classic scripts sharing one global scope, loaded in this order (`app.js` last):
| File | What |
|---|---|
| `css/01-*.css` .. `css/05-*.css` | All styles, split on the section markers and linked in order from index.html (cascade order matters): tokens, header, Portfolio, Board; card panel, forms, dialogs, phones; columns, title bar, DMs; rail, chat folds, queue; AI tester evidence |
| `js/usage-page.js` | The `#/usage` page (charts are hand-written SVG) |
| `js/inbox-style.js` | `INBOX_CSS`: the inbox styles, injected by inbox.js (loaded just before it) |
| `js/inbox-queue.js` | `paintQueue(shown, kindFilter)`: the inbox kind chips and the Next up line (AIG-159..162); called by inbox.js |
| `public/js/inbox-ai.js` | `aiFlickHtml`: the inbox's 🤖 AI passed view, one test at a time with the tester's evidence (AIG-192); inbox.js owns the list, clicks and keys |
| `js/inbox-decide.js` | ⚡ Decide pile and 🗂️ Topics (AIG-361): `decideList` / `decideItem` (answer-button questions via `askActions`, open quizzes), `decideHtml`, `decideAct` and the keys (1-4 answer, → skip, Enter open, Esc); `quizPanel` on the card (`.qz-opt`); the ⚡ Decide chip is added by `paintQueue`; texts `decide.*`, `card.quiz.*` |
| `public/js/glossary.js` | Dev words explained (AIG-102): the 📖 glossary page (#/glossary, searchable) and, with Setup's "Explain developer words" on, hover tooltips on those words anywhere (MutationObserver); words in the language files as gloss.<id>.word/.text/.also |
| `public/js/tour.js` | 🎓 Guided tour (AIG-95): three levels (new / refresh / anyway), a spotlight and bubble per stop (TOUR list of selectors), texts in the language files (tour.*) |
| `public/js/night.js` | 🌙 Night glance (AIG-209): `#/pop-night`, a calm red-tinted pop-out with the watchman per project; a slow amber glow only for stuck cards or real stand-up blockers |
| `js/inbox-state.js` | `IB`: the inbox's shared mutable state (items, tab, chat, flick, only...), plus helpers (`el`, `esc`, `post`, `isTask`...) and `load`/`apply`/`repaint`. The inbox files below are each a closure and share state and functions only through `IB` |
| `js/inbox-top.js` | `paintTop` (top-bar button and tab title), `announce` / `toggleAlerts` (new-question alerts) |
| `js/inbox-items.js` | `qHtml` / `kHtml` / `tHtml`, `skeleton` (page frame), `syncList` |
| `js/inbox-tabs.js` | `paintTabs` (project tabs), `paintChats` (Messages) |
| `js/inbox-page.js` | `paintPage`, `toast` |
| `js/inbox-actions.js` | `send`, `taskDone`, `accept`, `waitAndSee`, `startTester`, `acceptAiPassed`, `flickAct` and the AI view keys |
| `js/inbox.js` | Injects the styles; `onClick` / `onKey`, `show` (called by core.js), the poll; exports `window.Inbox` |
| `js/i18n.js` | Languages (AIG-124): `t(key, vars)`, `loadLang` (runs before the first render), `setLang`, `langPickHtml`; see "Languages" below |
| `js/core.js` | `state`, `api`, `esc`, `ago`, the router (`parseRoute`), `busy`/`refresh`/`render` (the 1s poll never wipes typing), `slug`/`curCard`/`setErr` |
| `js/format.js` | Card text: `withCode`, `spaceBullets`, `linkify`, `.md` links (`mdLinks`, opened by `showDocPath` in js/dialogs/); `md` (Docs renderer) |
| `js/attach.js` | `Attach`: 📎 button, paste-a-screenshot and pending chips for any reply box (card, inbox and chats), `upload` on send (`read` gives the files as base64 for a private DM), `shown` thumbnails under comments |
| `js/filters.js` | Search and filter bar; saved views (`viewsDialog`, `applyView`; stored on the project, last one used in localStorage) |
| `js/home.js` | Home page: `renderHome`, project bars, usage strip |
| `js/standup.js` | Stand-ups: `callStandup` (📣 buttons on the board and home), `standupButtons`, the `#/standups` report page (`renderStandups`, blockers first), the once-a-day `morningPrompt` pill (`suPick` to choose projects; day saved in localStorage `aigile.standupAsked`) |
| `js/board.js` | In flight and presence, `renderBoard`, swimlanes (`lanesOf`, `columnsHtml`), `cardHtml`, `poke`, drag and drop, the For you header buttons `tidyPile` and `testForMe` (🤖, AIG-300; AI-passed tests sort first in `forYouQueue`) |
| `js/card.js` | `cardFields`, assignee select, `renderCard` (Reply/Details/Test tabs), edit/delete/reply/verdict |
| `js/dialogs/*.js` | (AIG-351: `ideaDialog`/`sendIdea` in happening-columns.js, the top-bar 💡 button `#ideaBtn`, texts `idea.*`) Five files in load order: `shell-card-project-connect` (`openDialog`, New card, New project, Connect), `find-trial-setup-teams`, `happening-columns`, `card-view-picture-look`, `permissions-docs` (Docs). the inbox files share their state through the `IB` object in `inbox-state.js` |
| `js/leadquiz.js` | What kind of lead? (AIG-235..237): `QUIZ` (question -> settings), `leadQuiz`/`saveQuiz` dialog (offered once when the name is first saved), `leadPrefsHtml` the "Your lead" switches on the Setup page, `setLeadPref` |
| `js/pretend.js`, `js/pretend-setup.js` | 🧪 Pretend friend (AIG-322/323): pretend.js puts the "You're Davy (pretend)" bar on every page of the pretend board and defaults it to nl-BE (runs before app.js); pretend-setup.js is Setup's box (`pfBody`): start (swap invites or not), Open, Davy's invite code, Stop (keep or wipe); texts `pretend.*` |
| `js/dms-friends.js` (join part) | 🎟️ Invite a friend to AI-gile (AIG-347), in the same box: help level (🐣/🙂/😎), Make an invite link, Copy, open links with used / runs out in N days, join service address and key; texts `join.*`, QA area `join` |
| `js/dms-friends.js` | Setup's friends box for private DMs (AIG-311): the DMs on switch, Invite a friend (code + Copy), Add a friend (paste + name), per contact the 6 safety words, ✅ They match, Block, Remove; texts `dmf.*` |
| `js/share.js` | `Share` (AIG-304): the board's 🔗 button (`Share.button(p)` in board.js) and dialog (pick a contact, check the 6-word safety code, allowance ticks, send the offer; when live: the switch, dropped-while-off count, 👋 check the link, Unlink, Unlink and forget), and link offers in the inbox (`#ibShare`, painted from inbox-page.js: ✅ Link to a project or a new one / ✋ No). Polls `/api/shares` every 3s, plus the open project's `/inbound`. Shared cards (AIG-305): `laneHtml` (the 📥 From {friend} row above the board, board.js), `cardBtn` / `previewCard` (🔗 on the card panel: the four fields that go, scrub flags, Send / Send anyway / Stop sharing), `cardComments` and `commentMark` (their comments and sent / held marks in the Reply pane, card.js), `laneCard` (a lane card: plain text, links not clickable, replies, ➡️ Take into my Backlog). AIG-306: the live dialog's "let my team read" tick (`setTeamRead`, `#shareTeamRead`); `cardComments` also shows their status label (`statusHtml`), the description and files of a card I took (`filesHtml`: download links only, never an image), the test I handed them with their verdict and 🧪 Ask {friend} to test (`myTest`, `testDialog`, `sendTest`), and a test they handed me with ✅ Accept / ↩️ Send back (`theirTest`, `verdict`); `laneCard` shows the same for a lane card; the preview lists the attachments that would go. Texts `share.*` |
| `js/ask.js` | `Ask` (AIG-210): friends' questions in the inbox (`#ibAsk`, painted by inbox-page.js; `IB.asks` keeps the empty state away): the question as plain text, a size hint, ✅ Ask it / ✋ Not now. The 🙋 Ask button (label `ask.btn`, the other person's name) and the ask / answer tags in a friend's chat are in `js/dms.js` (`Dms.ask`, `askTag`) |
| `js/app.js` | Start-up: hashchange, the 1s poll, the new-build prompt; going quiet (`goQuiet`, `setNight` night theme); `pokeBadge` (top bar) |
