# Code map: QA and AI tester

- QA: `node tools/qa/qa.mjs [area ...]` (no args = all; `--list` shows them; `QA_PORT` changes the port, default 4390). It starts its own server on a temp data folder with a stub agent program, so the live board is never touched. Areas: `api`, `cli`, `board`, `card`, `filters`, `inbox`, `usage`, `presence`, `quiet`, `quietinbox`, `poke`, `blocked`, `docs`, `mdlinks`, `newproject`, `newscrum`, `perms`, `gobutton`, `attach`, `refresh`, `look`, `logos`, `guard`, `owner`, `setup`, `update`, `foryou`, `popout`, `popreopen`, `inboxonly`, `aiflick`, `tidy`, `poplist`, `glossary`, `tour`, `trial`, `pretend`, `watchman`, `nightglance`, `watchdm`, `restartpill`, `restartqueue`, `testorder`, `columns`, `cardview`, `steady`, `wip`, `lanes`, `quick`, `standup`, `views`, `steps`, `fynext`, `theme`, `chats`, `railorder`, `answerbtns`, `aitester`, `usagecheck`, `discover`, `starter`, `dms`, `dmchats`, `dminvite`, `ask`, `share`, `openit`, `testnotes`, `i18n`, `runin`, `ideabtn`, `decide`, `budget`, `notokens`, `teamroles`, `pack`, `shareboard`, `bump`, `plainnote`, `scrummaster`, `dmrules`, `friendpath` (AIG-1182: invite, join, DM send/reply/react, share, raise, phone width; `QA_SHOTS=<folder>` saves screenshots). The page areas need playwright (`cd tools/qa && npm i`; `node_modules` is git-ignored).
- QA files (AIG-165): `tools/qa/qa.mjs` is the runner only (args, `ORDER` of areas, run, summary; a new area goes at the end of `ORDER`). `tools/qa/lib.mjs` has the shared helpers (`startServer`, `check`, `mkProject`, `mkCard`, `getCard`, `say`, `openPage`, `noErrors`, `sleep`, `tmp`, `def`, `BASE`, `PORT`, `ROOT`; the failure count and current area are behind `setArea`/`getFailures`). `tools/qa/areas/*.mjs` hold the areas, each file calling `def(...)` and listed in qa.mjs: `api-cli` (api, cli, guard, update, proof), `board` (board, filters, columns, cardview, wip, lanes, views, steps, quick), `card` (card, steady, gobutton, attach, refresh, drafts, openit, testnotes, editor), `projects-docs` (docs, mdlinks, newproject, newscrum, perms, discover), `inbox` (inbox, foryou, fynext, queue, blocked, usage), `team-quiet-1..5-*` (presence, quiet, quietinbox, poke, wakenews, runtokens, watchman, keepgoing, limit, limitread, stuckonly, light, tester, verbose, nightglance, watchdm, runin), `chats-dms` (chats, answerbtns, dms, dmchats, dminvite), `standup-tester` (standup, aitester), `share` (share: two boards and a local relay, AIG-304; `share-cards.mjs` and `share-more.mjs` are its parts 2 and 3, called from it: shared cards and comments, AIG-305; the team fence, status labels, tests and verdicts, attachments, AIG-306; `share-roles.mjs` is part 4: owner-only `/api/shares`, the per-role allow/deny table, role scope, 🙋 Assign, AIG-307), `share-board` (area `shareboard`, AIG-324/325: a shared project as its own board on the friend's side, whole board or ticked cards, per role what shows and which buttons exist, the actions landing on the owner's side, nothing wakes; imports `startRelay`, `pair`, `until` from share.mjs), `look-setup-1..4-*` (look, logos, theme, popout, owner, setup, i18n).
- AI tester (AIG-163): `docs/TESTER.md` is its brief. `tools/tester/sandbox.mjs` runs a throwaway copy of the board on port 4399 (agents never woken). `tools/tester/look.mjs` opens a page, runs `--click/--fill/--press` steps, prints the visible text and saves one screenshot. CLI `tests` / `checked`, route `POST /cards/:id/aicheck`, card field `aiCheck`.
- Feature crawl (AIG-981): `tools/crawl/crawl.mjs [--only <text>] [--json]` runs the `check` of each entry in `docs/features/features.json` (`api` request, `ui` selector visible in 8 s, `cli` command, `qa` area names run once through `qa.mjs` on `CRAWL_PORT`+1) with its own server on `CRAWL_PORT` (default 4988); writes `docs/reports/crawl-YYYY-MM-DD.md` (Fail, No check, Slow >2 s, Pass). Entries with no check, an unknown area or a selector that is only a description count as "no check".

- Chat disk-error regression (AIG-1177): `node --test tools/qa/atrest-read-errors.test.cjs` injects temporary EACCES, EIO and EPERM read failures and checks that a read-modify-write stops with the existing encrypted history unchanged; missing chats still default to empty. Uses its own temporary data and secrets folder.
