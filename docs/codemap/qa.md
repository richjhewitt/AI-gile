# Code map: QA and AI tester

- QA: `node tools/qa/qa.mjs [area ...]` (no args = all; `--list` shows them; `QA_PORT` changes the port, default 4390). It starts its own server on a temp data folder with a stub agent program, so the live board is never touched. Areas: `api`, `cli`, `board`, `card`, `filters`, `inbox`, `usage`, `presence`, `quiet`, `quietinbox`, `poke`, `blocked`, `docs`, `mdlinks`, `newproject`, `newscrum`, `perms`, `gobutton`, `attach`, `refresh`, `look`, `logos`, `guard`, `owner`, `setup`, `update`, `foryou`, `popout`, `popreopen`, `inboxonly`, `aiflick`, `tidy`, `poplist`, `glossary`, `tour`, `trial`, `pretend`, `watchman`, `nightglance`, `watchdm`, `restartpill`, `restartqueue`, `testorder`, `columns`, `cardview`, `wip`, `lanes`, `quick`, `standup`, `views`, `steps`, `fynext`, `theme`, `chats`, `railorder`, `answerbtns`, `aitester`, `usagecheck`, `discover`, `dms`, `dmchats`, `share`, `openit`, `testnotes`, `i18n`, `runin`. The page areas need playwright (`cd tools/qa && npm i`; `node_modules` is git-ignored).
- QA files (AIG-165): `tools/qa/qa.mjs` is the runner only (args, `ORDER` of areas, run, summary; a new area goes at the end of `ORDER`). `tools/qa/lib.mjs` has the shared helpers (`startServer`, `check`, `mkProject`, `mkCard`, `getCard`, `say`, `openPage`, `noErrors`, `sleep`, `tmp`, `def`, `BASE`, `PORT`, `ROOT`; the failure count and current area are behind `setArea`/`getFailures`). `tools/qa/areas/*.mjs` hold the areas, each file calling `def(...)` and listed in qa.mjs: `api-cli` (api, cli, guard, update, proof), `board` (board, filters, columns, cardview, wip, lanes, views, steps, quick), `card` (card, gobutton, attach, refresh, drafts, openit, testnotes, editor), `projects-docs` (docs, mdlinks, newproject, newscrum, perms, discover), `inbox` (inbox, foryou, fynext, queue, blocked, usage), `team-quiet-1..5-*` (presence, quiet, quietinbox, poke, wakenews, runtokens, watchman, keepgoing, limit, limitread, stuckonly, light, tester, verbose, nightglance, watchdm, runin), `chats-dms` (chats, answerbtns, dms, dmchats), `standup-tester` (standup, aitester), `share` (share: two boards and a local relay, AIG-304) , `dm-invite` (Setup friends box, two boards and a relay, AIG-311), `look-setup-1..4-*` (look, logos, theme, popout, owner, setup, i18n).
- AI tester (AIG-163): `docs/TESTER.md` is its brief. `tools/tester/sandbox.mjs` runs a throwaway copy of the board on port 4399 (agents never woken). `tools/tester/look.mjs` opens a page, runs `--click/--fill/--press` steps, prints the visible text and saves one screenshot. CLI `tests` / `checked`, route `POST /cards/:id/aicheck`, card field `aiCheck`.
